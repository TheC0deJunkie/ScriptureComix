**4. Quran:**

Source: `AL-QURAN_WITH_TRANSLATION_AND_TRANSLITERATION/AL-QURAN_WITH_TRANSLATION_AND_TRANSLITERATION.json`

Source format: `{ "chapters": { "1": { "total_verses": 7, "verses": { "1": { "translation_eng": "...", ... }, "2": {...} } } } }`

Normalization rules:
- **Al-Fatiha (surah 1):** Source has 7 verses where verse 1 is Basmala. Remap: store verse 1's `translation_eng` as `basmala` field in the manifest entry for Al-Fatiha. Renumber source verses 2-7 as output verses 1-6. Output file has 6 ayahs.
- **Al-Tawbah (surah 9):** Has no Basmala — no special handling needed.
- **All other surahs:** Use verse numbers as-is from source. Basmala is implicit and not counted.
- **Footnote stripping:** For each `translation_eng` value, strip inline footnotes. Strategy: remove digit-only sequences surrounded by non-digit characters (existing `cleanTranslation` approach), AND truncate at `\n` followed by paragraph-like text (footnote body). If text contains `\n` and the text after `\n` is >50 chars, truncate at the `\n`.
- **Surah slugs:** Use kebab-case of Arabic transliterated names from a QURAN_SLUG_MAP with all 114 entries. Example: `1: { slug: 'al-fatiha', displayName: 'Al-Fatiha' }`, `2: { slug: 'al-baqarah', displayName: 'Al-Baqarah' }`, etc.
- **Flat verse map for Quran:** Keys are just `"1"`, `"2"`, etc. (no chapter prefix — each surah file IS one chapter). So Al-Fatiha output: `{ "1": "All praise...", "2": "The Lord...", ... "6": "..." }`

Write to `public/data/quran/yusuf-ali/{slug}.json`
